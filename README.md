# علّامة (Aallama)
واجهة ويب متقدمة للتواصل مع Ollama AI بشكل رسومي.

## الهيكل الرئيسي
- client/: واجهة المستخدم (HTML, JS, CSS)
- server/: الخادم Node.js لإدارة الاتصال مع Ollama وإعدادات النموذج والجلسات والأدوات

## الإعداد والتشغيل
1. npm install
2. تشغيل Ollama server محليًا
3. node server/index.js
