# علّامة (Allama / 3allama) 🤖

واجهة ويب متقدمة، أنيقة، وخفيفة الوزن للتعامل مع **Ollama AI** محلياً. تم تصميم "علّامة" لتوفير تجربة مستخدم مشابهة لـ ChatGPT و Gemini ولكن مع تحكم كامل وخصوصية تامة، ودعم كامل للغة العربية.

## 🚀 المميزات الجديدة (ما هو الجديد في v1.2.0)

- **استوديو الوكلاء (Agent Studio):** أنشئ وكلاء مخصصين بأسماء وأيقونات وتعليمات برمجية (System Prompt) خاصة لكل مهمة.
- **نظام الإضافات الديناميكي (Dynamic Plugins):** مهارات جديدة للذكاء الاصطناعي تشمل:
    - **الآلة الحاسبة:** حل المسائل الرياضية المعقدة.
    - **قارئ PDF:** تحليل ملفات PDF المرفوعة مباشرة.
    - **الوقت وShell:** الوصول للوقت وتنفيذ أوامر النظام.
    - **طلبات الويب:** جلب محتوى من روابط خارجية.
- **مراقبة النشاط (Activity Monitor):** شاهد خطوات عمل الوكيل واستخدامه للأدوات في الوقت الحقيقي داخل فقاعة المحادثة.
- **قاعدة المعرفة (RAG):** ارفع ملفاتك النصية (.txt, .md, .json) ليستخدمها الوكيل كمرجع للإجابة على أسئلتك.
- **دعم التفكير (Thinking Support):** واجهة مخصصة لعرض "التفكير الداخلي" للنماذج الذكية (مثل DeepSeek-R1).

## ✨ المميزات الأساسية

- **واجهة Mobile-First:** تصميم متجاوب تماماً يعمل بسلاسة على الهواتف.
- **الهوية البصرية لـ Ollama:** تصميم بسيط وأنيق باللونين الأبيض والأسود.
- **دعم البث المباشر (Streaming):** طباعة الرد كلمة بكلمة في الوقت الفعلي.
- **دعم الرؤية (Vision):** إرسال الصور للنماذج التي تدعم ذلك.
- **التخزين المتوافق:** نظام تخزين JSON خفيف يعمل بسلاسة على كافة البيئات بما فيها Termux.

## 📂 هيكلية المشروع

```text
Allama/
├── client/              # ملفات الواجهة الأمامية (HTML, JS, CSS)
├── server/              # ملفات الخادم (Node.js)
│   └── plugins/         # نظام الأدوات المخصص
├── data/                # مجلد تخزين البيانات والملفات
└── package.json         # التبعات والإعدادات
```

## 📦 التنصيب والتشغيل

1. **تحميل المشروع:**
   ```bash
   git clone <url-of-repo>
   cd Allama
   ```

2. **تثبيت التبعات:**
   ```bash
   npm install
   ```

3. **بدء التشغيل:**
   ```bash
   npm start
   ```
   التطبيق متاح على: `http://localhost:3000`
