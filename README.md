# علّامة (Allama / 3allama) 🤖

واجهة ويب متقدمة، أنيقة، وخفيفة الوزن للتعامل مع **Ollama AI** محلياً. تم تصميم "علّامة" لتوفير تجربة مستخدم مشابهة لـ ChatGPT و Gemini ولكن مع تحكم كامل وخصوصية تامة، ودعم كامل للغة العربية.

## 🚀 المميزات الرئيسية

- **واجهة محادثة عصرية:** تصميم متجاوب يدعم اللغة العربية (RTL) مع فقاعات محادثة واضحة (المستخدم على اليمين، والذكاء الاصطناعي على اليسار).
- **دعم الرؤية (Vision):** إمكانية إرسال الصور للنماذج التي تدعم ذلك، مع تعطيل الزر تلقائياً للنماذج التي لا تدعمها.
- **استدعاء الدوال (Tool Calling):** دعم متقدم لتنفيذ المهام عبر الأدوات:
    - **معرفة الوقت:** الحصول على التاريخ والوقت الحالي بدقة.
    - **تنفيذ الأوامر:** تنفيذ أوامر النظام مباشرة (يستخدم بحذر).
    - **طلبات الويب:** جلب محتوى من روابط الإنترنت.
- **التخزين المحلي (Termux Compatible):** استخدام نظام تخزين JSON خفيف الوزن لضمان التوافق التام مع بيئة Termux وأندرويد دون مشاكل في مكتبات SQLite.
- **إدارة الجلسات:** حفظ تاريخ المحادثات في قائمة جانبية (Drawer) مع إمكانية حذفها أو تغيير عناوينها.
- **تنسيق Markdown:** عرض الإجابات بتنسيق Markdown الجميل مع دعم تظليل الكود البرمجي (Syntax Highlighting).
- **إعدادات متقدمة:** التحكم في "رسالة النظام" (System Prompt)، ودرجة الحرارة (Temperature)، وتفعيل أو تعطيل الأدوات لكل محادثة.
- **الوضع الليلي (Dark Mode):** واجهة مريحة للعين يمكن التبديل إليها بسهولة.

## 📂 هيكلية المشروع

```text
Allama/
├── client/              # ملفات الواجهة الأمامية
│   ├── index.html       # الهيكل الرئيسي والتصميم (Tailwind)
│   └── app.js           # منطق التفاعل والاتصال بالـ API
├── server/              # ملفات الخادم (Node.js)
│   ├── index.js         # نقطة الدخول الرئيسية والمسارات
│   ├── db.js            # نظام التخزين (JSON File Database)
│   ├── ollama.js        # منطق الاتصال بسيرفر Ollama
│   └── tools.js         # تعريف ومعالجة الأدوات (Functions)
├── data/                # مجلد تخزين البيانات (يحتوي على allama.json)
├── package.json         # التبعات والإعدادات
└── README.md            # التوثيق الحالي
```

## 🛠️ المتطلبات

- **Node.js** (إصدار 18 أو أحدث).
- **Ollama** مثبت ويعمل على جهازك.

## 📦 التنصيب والتشغيل

1. **تحميل المشروع:**
   ```bash
   git clone <url-of-repo>
   cd Allama
   ```

2. **تثبيت التبعات:**
   تم اختيار التبعات لتكون خفيفة جداً ومتوافقة مع Termux:
   ```bash
   npm install
   ```

3. **تشغيل Ollama:**
   تأكد من أن سيرفر Ollama يعمل في الخلفية:
   ```bash
   ollama serve
   ```

4. **بدء تشغيل علّامة:**
   ```bash
   npm start
   ```
   سيفتح التطبيق على الرابط: `http://localhost:3000`

## 🧩 التعديل وإضافة مهارات (Tools)

يمكنك تحسين المشروع وإضافة مهارات جديدة للذكاء الاصطناعي عبر تعديل ملف `server/tools.js`:
1. أضف تعريف الدالة الجديدة في مصفوفة `toolsDefinition`.
2. أضف الكود البرمجي الذي سينفذ المهمة في كائن `handlers`.
