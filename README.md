# علّامة (Allama / 3allama) 🤖

واجهة ويب متقدمة، أنيقة، وخفيفة الوزن للتعامل مع **Ollama AI** محلياً. تم تصميم "علّامة" لتوفير تجربة مستخدم مشابهة لـ ChatGPT و Gemini ولكن مع تحكم كامل وخصوصية تامة، ودعم كامل للغة العربية.

## 🚀 المميزات الرئيسية

- **واجهة Mobile-First:** تصميم متجاوب تماماً يعمل بسلاسة على الهواتف والأجهزة اللوحية.
- **الهوية البصرية لـ Ollama:** واجهة بسيطة وأنيقة باللونين الأبيض والأسود تعكس الهوية الرسمية لـ Ollama.
- **دعم البث المباشر (Streaming):** طباعة الرد كلمة بكلمة في الوقت الفعلي لتجربة محادثة أسرع.
- **إظهار التفكير (Thinking Display):** عرض عملية التفكير والنقاش الداخلي للنماذج التي تدعم ذلك (مثل نماذج Thinking).
- **انميشن الانتظار:** مؤشر بصري جذاب يظهر أثناء انتظار رد النموذج.
- **دعم الرؤية (Vision):** إرسال الصور للنماذج التي تدعم ذلك.
- **استدعاء الدوال (Tool Calling):** تنفيذ مهام برمجية مثل معرفة الوقت، تنفيذ أوامر النظام، وطلبات الويب.
- **التخزين المتوافق:** نظام تخزين JSON خفيف الوزن متوافق تماماً مع Termux.

## 📦 التنصيب والتشغيل

1. **تحميل المشروع:**
   ```bash
   git clone <url-of-repo>
   cd Allama
   ```

2. **تثبيت التبعات:**
   ```bash
   npm install
   ```

3. **بدء التشغيل:**
   ```bash
   npm start
   ```
   التطبيق متاح على: `http://localhost:3000`
